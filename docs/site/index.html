AutoPay

시작하기

필요한 것: Node 20+, pnpm 9, Chrome, Claude Code.

  1. 한 줄로 설치·빌드

    저장소 루트에서 실행하면 의존성 설치, 빌드, 연결 토큰 준비(클립보드에 복사)까지 끝납니다.

    pnpm bootstrap

  2. Chrome에 익스텐션 로드

    chrome://extensions → 개발자 모드 → "압축해제된 확장 프로그램 로드" → packages/broker-extension/.output/chrome-mv3. 다시 빌드한 뒤에는 새로고침 ⟳만 누르면 됩니다.

  3. 옵션에서 연결 · 한도 설정

    MCP 브리지에 토큰을 붙여넣고(이미 클립보드에 있음), 결제 한도를 저장하세요. 기본값은 0원이라 설정 전에는 모든 결제가 거절됩니다. 상단 시작하기 카드가 남은 단계를 보여줍니다.

  4. 쿠팡 준비

    쿠팡에 직접 로그인하고, 쿠팡 앱에서 원터치 결제를 켜 둡니다. AutoPay는 로그인 정보를 다루지 않습니다.

  5. Claude Code에서 요청

    저장소 폴더에서 Claude Code를 실행(이미 실행 중이면 재시작)하고 말하면 됩니다.

    아이패드 에어2 검정 케이스 쿠팡에서 주문해줘

안전장치

"AI를 막는 것"이 아니라 "AI가 훔칠 비밀 자체가 없게" 설계했습니다.

AutoPay가 하는 일

  • 건당·일·월 한도와 일 횟수 제한
  • 허용 쇼핑몰·결제수단 제한
  • 화면의 실제 금액을 직접 읽어 대조
  • 승인 후 상품·금액이 바뀌면 결제 중단
  • 결제 진행 중 AI의 페이지 조작 잠금
  • 모든 시도(성공·거절·실패) 기록과 즉시 알림

AutoPay·AI가 절대 하지 않는 일

  • 결제 비밀번호·카드번호 저장이나 입력
  • 보안 키패드 조작, 이상거래탐지 우회
  • 로그인 정보 저장이나 입력
  • AI에게 비밀을 돌려주는 API

결제 경로별 사람 개입

국내 결제수단은 자동 승인을 막도록 설계되어 있어, 경로마다 사람이 하는 일이 다릅니다.

FAQ

결제 중에 비밀번호 입력창이 떴어요.

원터치가 켜져 있어도 쿠팡이 위험도를 판단해 비밀번호를 다시 요구할 수 있습니다(쿠팡의 보안 기능). AutoPay가 알림을 보내면 그 결제 탭에서 본인이 직접 입력하세요. 약 3분 안에 입력하면 결제가 완료되고 기록됩니다.

비밀번호를 설정에 넣어 두면 자동으로 입력해 줄 수 있나요?

아니요. 비밀번호를 저장하는 순간 "AI가 훔칠 비밀이 없다"는 전제가 깨지고, 보안 키패드를 대신 누르는 것은 결제사의 보안 통제를 우회하는 일입니다. 텔레그램 같은 원격 채널로 전달하는 것도 같은 이유로 지원하지 않습니다. 원격 승인이 필요하면 폰 승인 결제수단(카카오·토스)이 그 역할을 합니다.

결제가 모두 "거절"돼요.

설치 직후 한도가 0원(전부 거절)이기 때문입니다. 옵션의 "결제 한도"에서 건당·일·월 한도와 일 횟수를 정하고 저장하세요.

"브리지 연결 안 됨"이라고 나와요.

옵션의 MCP 브리지에 토큰이 등록되어 있는지, Claude Code가 저장소 폴더에서 실행 중인지 확인하세요. 토큰이 기억나지 않으면 pnpm bootstrap을 다시 실행하면 클립보드에 복사됩니다. 익스텐션을 다시 빌드했다면 chrome://extensions에서 새로고침하세요.

패스프레이즈 잠금 해제는 꼭 해야 하나요?

쿠팡만 쓴다면 필요 없습니다. 카카오·토스 결제에 쓰는 본인 식별 정보(휴대폰·생년월일)를 암호화하는 키입니다.

다른 AI 브라우저 익스텐션과 같이 써도 되나요?

AutoPay는 다른 익스텐션의 권한을 제한할 수 없습니다. 쿠키·사이트 접근 권한이 있는 AI 익스텐션은 로그인 세션을 읽을 수 있으니, 자동 쇼핑용 브라우저 프로필을 따로 쓰는 것을 권장합니다.

AutoPay는 개발 중인 프로토타입입니다. 실제 결제 전 정책 한도를 반드시 확인하세요. 자세한 설계: AGENTS.md · docs/spec/
